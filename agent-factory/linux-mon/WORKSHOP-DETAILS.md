# Linux Monitoring: Workshop Details

## Short description

Check a Linux server and its applications, then turn fresh evidence into a concise shift handover.

## Long description

In this 15-minute lab, IT and DevOps practitioners clone a supplied Agent Factory flow and configure six read-only MCP tools. They ask natural operations questions, distinguish resource readings from application checks, inspect observation times and scope, and customize a four-bullet handover. An optional challenge uses recorded history to assess change over time. The instructor supplies the monitored machine, applications and MCP connection before class.

## Outline

1. Clone and inspect the four-component flow — 3 minutes.
2. Review the connection, selected tools and instructions — 3 minutes.
3. Ask two operations questions and inspect evidence — 5 minutes.
4. Customize and test a short handover — 4 minutes.
5. Optional: inspect change over time using available history.

## Delivery

- Mode: fastlab; one lab that can be added to the existing Agent Factory workshop.
- Audience: IT and DevOps practitioners familiar with the introductory builder exercise.
- Preview: serve this folder over HTTP and open `index.html`.
- Existing-workshop integration: add a manifest tutorial whose filename points to `../../linux-mon/linux-mon.md` from `workshops/aiw2026/`.
- Required preparation: shared example, accessible MCP connection, workshop model and working monitoring tools.
- FreeSQL: not used; this agent uses MCP monitoring tools.
- Timing: estimate; the history challenge is outside the 15-minute core exercise.
